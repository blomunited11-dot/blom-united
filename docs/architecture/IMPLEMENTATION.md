# التنفيذ

- هذا إصدار أولي قابل للتطوير، وليس نظامًا مكتملًا أو مختبرًا في الإنتاج.
- يجب تحميل الخطوط والشعار والصور المعتمدة قبل اعتماد الواجهة.
- مفاتيح Supabase العامة فقط في NEXT_PUBLIC؛ لا تستخدم service role في الواجهة.
- تطبيق migrations يحتاج موافقة واعتماد بيئة Supabase المناسبة.
- Cloudflare Workers يتطلب اختبار توافق حزمة Next.js واختيار adapter متوافق، ولم يُضبط النشر التلقائي عمدًا.
- تحديث المحتوى المنشور ينبغي أن يستخدم قراءات وقت الطلب أو سياسة إبطال كاش مناسبة.
