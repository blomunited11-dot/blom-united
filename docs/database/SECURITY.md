# تنبيه أمني

ترحيل 001 هو المخطط الأساسي، وترحيل 002 يقيد الكتابة مبدئيًا إلى المالك فقط ويصلح سياسة ربط الصور. لا تطبق الترحيلات على الإنتاج قبل فحصها داخل بيئة اختبار، ولا تمنح أدوار المحررين صلاحيات كتابة حتى تتوفر عمليات نشر مقيّدة على مستوى القطاع.

لإنشاء أول مالك: أنشئ مستخدمًا عبر Supabase Auth، ثم أضف user_id الخاص به إلى admin_memberships بدور owner من SQL Editor بصلاحية إدارية، بعد التحقق من هويته. لا تخزن بيانات تسجيل الدخول في GitHub.

لا تزال إدارة الصور وStorage وسياسات bucket، وسجل التدقيق التلقائي، وصلاحيات النشر المتدرجة بحاجة إلى تنفيذ واختبار.
